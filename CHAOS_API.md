# Chaos Engine API

The `chaos.js` module provides a central core for predictably unpredictable behavior. None of these functions are reliable.

## Audio Functions
- `playErrorBeep()`: Plays an unpleasant beep.
- `playSuccessChime()`: Deceives the user with a pleasant sound.
- `playTeaPour()`: Brown noise filtering. 
- `playGlitchSound()`: High-pitch sawtooth wave.
- `playDramaticBuzz()`: Low-frequency square wave for crashes.
- `playTeaChime()`: A 4-note melodic chime.

## Visual Effects
- `triggerScreenShake(intensity)`: Shakes the DOM violently.
- `corruptText(text)`: Scrambles strings via zalgo-esque characters.
- `spawnFloatingTea(container)`: Unleashes an armada of tea emojis.

## Constants & Generators
- `randomLoadingText()`: Returns a fake objective like "Downloading more RAM..."
- `getRandomPopup()`: Returns unhelpful status messages.
- `getRandomModal()`: Obtains a complete fake UI modal configuration.
- `getSentienceMessage()`: Fake AI observations.
- `getRandomInterference()`: Intersystem feature collision messages.
